Garbage Man was written by Peter C. Davidson in 2009.

I hope you enjoy it.


HOW TO PLAY

-Load the program onto your TI-83/84 Plus
-Open “GARBAGE” in the Program menu or in a file manager such as MirageOS (MirageOS can run it while archived).
-Follow the onscreen prompts to play! (When in doubt, press Enter.)
